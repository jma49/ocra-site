# Security policy

This repository is the ocra website and manual (https://ocracloud.com). For a vulnerability in ocra itself, follow the engine's policy: https://github.com/jma49/Open-CR-Agent/security/policy.

## Reporting a vulnerability in the site

Report it privately, through GitHub: [Security → Report a vulnerability](https://github.com/jma49/ocra-site/security/advisories/new), or email [meetjincheng@yahoo.com](mailto:meetjincheng@yahoo.com) with "ocra site security" in the subject. Do not open a public issue or pull request for it.

ocra has one maintainer: expect an acknowledgement within 7 days and a fix deployed as soon as it is ready.
